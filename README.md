# pastebin-system-design

This is a working implementation of the Pastebin design from
[system-design-primer](https://github.com/donnemartin/system-design-primer/blob/master/solutions/system_design/pastebin/README.md).

The repo is built in two stages:

1. **`v0-bad-practices`**: the first version runs, but it is built on purpose with some questionable choices.
2. **`v1-reviewed`**: those choices are reviewed and fixed one by one. Each fix is traced back to a finding in `docs/REVIEW.md`.
